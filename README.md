# HongGuoPurify

红果短剧（`com.phoenix.video`）净化插件的独立重建项目，基于用户提供的原版 `红果短剧净化_1.0.1_无根.deb` 进行功能还原。

## 当前代码覆盖范围

- **广告净化**：阅读/听书/短剧广告视图清理；短剧广告请求、暂停广告、贴片广告、推荐流、剧情触点、侧栏贴片、视频合集评论广告等候选 Hook。
- **页面净化**：推广入口、评价邀请、金币挂件与引导气泡、章节末尾圈子/讨论/送礼物/作者寄语、章末快捷按钮、底部福利/短剧入口、我的页卡片与发帖按钮、书城/书架入口、弹幕、作者声明、系列剧集、热评、剧标签、AI 备案号、榜单排名等。
- **侧栏与红点**：屏蔽已识别的红点更新路径；游戏中心过滤只针对识别为游戏中心/小游戏的侧栏项目。
- **播放控制**：默认倍速、清晰度锁定、启动页偏好、短剧进入时抑制自动播放、播放清屏/暂停退出清屏、进度条时长标签。
- **原生入口**：尝试显示应用原生下载入口；不伪造下载成功、不绕过服务器授权或付费限制。
- **设置界面**：插件设置入口、总开关、功能独立开关、默认倍速、清晰度偏好、启动页偏好和顶部导航设置。

## 功能边界

本项目不是逐字节相同的二进制克隆。原版字符串和符号能帮助识别功能，但不能单独证明每个方法在所有红果版本中都存在或具有相同语义。每个 Hook 都会检查运行时类、选择器、参数数量及关键类型编码；不匹配时跳过并记录日志。

原版目录中的“会员状态伪装”涉及修改会员/广告权益相关状态，因此重建版不会伪造会员资格、订阅到期或服务端权益；该项在设置中保持禁用。原版目录中没有可识别标题的 38、39 项不作为可用功能展示。

## 构建

在 GitHub 仓库的 **Actions → Build HongGuoPurify → Run workflow** 运行构建。成功后，在对应运行的 Artifacts 中下载 `HongGuoPurify-rootless-deb`。

## 偏好文件

`/var/mobile/Library/Preferences/com.xiaoye.hongguopurify.plist`

主要键：
- `enabled`：插件总开关
- `feature.<编号>`：各功能独立开关
- `defaultSpeed`：默认倍速
- `lockResolution`、`lockResolutionEnabled`：清晰度偏好及启用开关
- `startupTab`、`startupTabEnabled`：默认启动页偏好及启用开关
- `startupTop`：启动时隐藏顶部导航

## 验证状态

构建成功只代表 Theos 编译与打包完成，不代表每个功能都已在真机逐项验证。不同红果版本可能更改类名、选择器、返回类型或业务流程。请在可恢复的测试环境中逐项检查；若某功能无效，请提供红果版本和设备日志，再根据实际运行时信息修正，避免继续盲目添加猜测 Hook。
